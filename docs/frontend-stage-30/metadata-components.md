# Metadata Components

Reusable components added:
- `MetadataManager`
- `AssignmentManager`
- `ExpiryStatus`

`MetadataManager` provides:
- list loading
- create/edit form
- backend validation/error display
- archive/delete-style confirmation actions
- expiry badges
- relation selects
- date and numeric field handling

`AssignmentManager` provides:
- assignment listing
- create/edit forms
- activate/end/cancel confirmation actions
- organization-aware payloads

These components are intentionally small and can be reused for later document, compliance, and attachment-like metadata screens.
