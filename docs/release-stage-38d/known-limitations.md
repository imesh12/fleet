# Known Limitations

- Browser screenshot automation was not available in this environment.
- Live pixel-level viewport checks were not completed through a visual browser session.
- The Next.js build still emits the known TypeScript project-reference warning while completing successfully.
- Prisma still emits the known `package.json#prisma` deprecation warning for Prisma 7 migration planning.
- DEMO-OSAKA and DEMO-YOKOHAMA intentionally contain minimal data for tenant switching, while DEMO-TOKYO contains the full demo dataset.
- Map rendering remains map-ready rather than Leaflet/MapLibre integrated.
