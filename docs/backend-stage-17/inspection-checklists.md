# Inspection Checklists

APIs:
- `GET /api/v1/admin/inspection-checklists`
- `POST /api/v1/admin/inspection-checklists`
- `GET /api/v1/admin/inspection-checklists/:id`
- `PATCH /api/v1/admin/inspection-checklists/:id`
- `POST /api/v1/admin/inspection-checklists/:id/activate`
- `POST /api/v1/admin/inspection-checklists/:id/deactivate`
- `POST /api/v1/admin/inspection-checklists/:id/items`
- `PATCH /api/v1/admin/inspection-checklists/:id/items/:itemId`
- `DELETE /api/v1/admin/inspection-checklists/:id/items/:itemId`

Checklist item types:
- `BOOLEAN`
- `TEXT`
- `NUMBER`
- `PHOTO`
- `PASS_FAIL`
