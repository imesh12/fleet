# Stage 17: Maintenance Foundation API

Stage 17 adds organization-scoped maintenance planning foundations.

Implemented:
- Maintenance categories
- Maintenance service tasks
- Inspection checklist templates and items
- Vehicle maintenance plans and plan tasks
- Maintenance requests
- Maintenance work order planning
- Maintenance due/readiness summaries
- Maintenance due background job support
- Optional notification delivery placeholders for due maintenance

Out of scope:
- Mechanic execution workflow
- Inventory purchasing
- Fuel
- Reports
- Payroll
- Billing
- Frontend screens

Legacy HTML note:
- Legacy HTML files were not deleted, moved, or edited.
- Secret-sensitive legacy settings files remain untouched.
