# Stage 29: Vehicle + Driver CRUD Forms

Stage 29 adds safe create/edit workflows for vehicle and driver registry records.

- Vehicle create route.
- Vehicle edit route.
- Driver create route.
- Driver edit route.
- Relation dropdown loading.
- Basic frontend validation.
- Backend envelope error display.
- Toast notifications.
- Redirect to detail after save.
