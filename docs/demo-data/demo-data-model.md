# Demo Data Model

The seed uses existing Prisma models only. No schema changes or new business modules were added.

Seed coverage includes:

- Tenant/customer foundation: organizations, memberships, settings, customers, contacts, and locations.
- Operational master data: departments, business units, vendors, categories, contracts, service areas, route groups, and templates.
- Fleet foundation: vehicle types, groups, makes, models, vehicles, documents, devices, compliance, assignments, and driver records.
- Operations: service routes/stops, trip templates, planned trips, dispatch queues, executed trips, lifecycle events, and dispatch actions.
- Tracking: providers, credential metadata placeholders, provider health, external devices, mappings, sync runs, alert rules/events, latest positions, telemetry history, geofences, geofence events, notifications, and escalations.
- Maintenance/fuel: categories, tasks, checklists, plans, requests, work orders, fuel types, cards, tanks, policies, requests, and entries.
- Reports/admin: report categories/definitions/presets/runs/exports, dashboard widgets/snapshots, jobs, notification providers/templates/deliveries, storage metadata, attachments, retention policies, and feature flags.

Manager-skipped modules remain Coming Soon only and receive no business seed data.
