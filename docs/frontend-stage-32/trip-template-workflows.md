# Trip Template Workflows

Integrated APIs:
- `GET/POST/PATCH /admin/trip-templates`
- `POST /admin/trip-templates/:tripTemplateId/activate`
- `POST /admin/trip-templates/:tripTemplateId/deactivate`
- `GET /admin/trip-templates/:tripTemplateId`
- `POST/PATCH/DELETE /admin/trip-templates/:tripTemplateId/stops/:stopId`

Trip templates are surfaced under the operations routes workflow because they are planning metadata tied to route patterns.
