# File Attachments

APIs:
- `GET /api/v1/admin/attachments`
- `POST /api/v1/admin/attachments`
- `POST /api/v1/admin/attachments/:id/archive`

Supported entity types:
- `vehicle`
- `vehicle_document`
- `driver`
- `driver_license`
- `driver_document`
- `maintenance_request`
- `maintenance_work_order`
- `fuel_entry`
- `report_run`
- `organization`
- `customer_account`

Attachments are links only. They do not move or copy file bytes.
