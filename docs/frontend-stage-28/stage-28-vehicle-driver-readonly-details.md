# Stage 28: Vehicle + Driver Read-Only Detail Slice

Stage 28 adds richer read-only fleet list and detail pages for vehicles and drivers.

## Delivered

- Vehicle list with search/status filters, pagination, status badges, and detail links.
- Vehicle detail route with summary, classification, documents, devices, compliance, maintenance, fuel placeholder, and tracking position preview.
- Driver list with search/status filters, pagination, status badges, and detail links.
- Driver detail route with summary, contact/employment info, skills, licenses, documents, compliance, assignments, and readiness placeholder.
- Shared read-only detail components.

## Not Included

- Vehicle create/edit forms.
- Driver create/edit forms.
- File uploads.
- Device attachment mutations.
- Live map UI.
