# Visual QA Checklist

## Desktop

- Sidebar active state is visible.
- Topbar organization and user controls fit.
- Dashboard cards show non-zero DEMO-TOKYO values.
- Tables do not overflow the page shell.
- Profile hero cards align with quick actions.

## Tablet

- Page headers wrap cleanly.
- Detail grids avoid clipping.
- Metadata managers keep action buttons usable.
- Tracking and operations panels remain readable.

## Mobile

- Hamburger button is visible.
- Drawer opens and closes by button, backdrop, Escape, and navigation.
- Organization selector is accessible.
- Tables scroll horizontally inside cards.
- Forms stack cleanly.

## Module Checks

- Vehicles: registration, status, odometer, documents, devices, compliance.
- Drivers: avatar, employee number, license expiry, skills, assignments.
- Operations: route stop order, trip statuses, dispatch validation panels.
- Tracking: last seen age, stale/offline badges, telemetry density.
- Maintenance/Fuel: due/overdue emphasis, units, currency, statuses.
- Reports/Admin: summaries, raw metadata, settings, jobs, notifications.

## Accessibility

- Focus outlines are visible.
- Buttons have clear labels.
- Status text is not represented only by color.
- Drawer has dialog semantics.
