# Stage 18: Fuel Foundation API

Stage 18 adds organization-scoped fuel foundations for fleet fuel operations.

Implemented:
- Fuel types
- Fuel vendor profiles linked to existing vendors
- Fuel cards
- Fuel tanks/storage
- Fuel policies and ordered rules
- Fuel requests
- Fuel entries with receipt metadata placeholders
- Fuel alert read API
- Fuel alert background job support
- Notification delivery placeholders for configured fuel alerts

Out of scope:
- Frontend
- Reports
- Payroll
- Billing
- Inventory purchasing
- Accounting integration

Legacy HTML note:
- Legacy HTML files were not deleted, moved, or edited.
- Secret-sensitive legacy settings files remain untouched.
