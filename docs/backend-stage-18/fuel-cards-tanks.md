# Fuel Cards + Tanks

Fuel card APIs:
- `GET /api/v1/admin/fuel-cards`
- `POST /api/v1/admin/fuel-cards`
- `GET /api/v1/admin/fuel-cards/:id`
- `PATCH /api/v1/admin/fuel-cards/:id`
- `POST /api/v1/admin/fuel-cards/:id/activate`
- `POST /api/v1/admin/fuel-cards/:id/deactivate`
- `POST /api/v1/admin/fuel-cards/:id/block`
- `POST /api/v1/admin/fuel-cards/:id/archive`

Fuel tank APIs:
- `GET /api/v1/admin/fuel-tanks`
- `POST /api/v1/admin/fuel-tanks`
- `GET /api/v1/admin/fuel-tanks/:id`
- `PATCH /api/v1/admin/fuel-tanks/:id`
- `POST /api/v1/admin/fuel-tanks/:id/update-level`
- `POST /api/v1/admin/fuel-tanks/:id/activate`
- `POST /api/v1/admin/fuel-tanks/:id/deactivate`

Fuel units:
- `LITER`
- `GALLON`
- `KWH`
