# Coming Soon Menu/Page

Skipped manager modules are represented as navigation and page metadata only.

Examples:

- Inventory
- Tyres
- Consumables
- Attendance
- Payroll
- Import/Export
- Bulk Upload
- Accounting
- Billing

```json
{
  "title": "Inventory",
  "slug": "inventory",
  "path": "/coming-soon/inventory",
  "status": "COMING_SOON",
  "moduleKey": "inventory",
  "comingSoonMessage": "Inventory is planned and will be available in a future Trackigniter8 stage."
}
```
