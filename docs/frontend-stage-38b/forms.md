# Forms

Updated shared form primitives:

- `FormField`
- `FormSection`
- `FieldGrid`
- `TextInput`
- `TextArea`
- `SelectInput`
- `DateInput`
- `NumberInput`
- `FormActions`
- `MetadataManager`
- `SearchFilterBar`

Improvements:

- Tokenized input surfaces and focus rings.
- Required markers handled by `FormField`.
- Disabled/loading states are more readable.
- Section spacing is more consistent.
- Metadata forms preserve existing create/edit/delete behavior.
