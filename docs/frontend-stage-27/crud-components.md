# CRUD Components

Added reusable frontend components:

- `FormField`
- `TextInput`
- `TextArea`
- `SelectInput`
- `FormActions`
- `ConfirmDialog`
- `ToastProvider`
- `PaginationControls`
- `SearchFilterBar`
- `EmptyState`
- `ErrorAlert`
- `AdminCrudPage`

`AdminCrudPage` handles:

- list fetching.
- search.
- status filtering.
- create form.
- edit form.
- activate/deactivate mutation.
- confirmation dialog.
- pagination metadata.
- organization context.
- backend envelope errors.
- refresh after mutation.
