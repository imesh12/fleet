# Stage 20: Menu / Page Placeholder Foundation

Stage 20 adds backend metadata for application navigation, page registry, coming-soon placeholders, and feature flags.

Implemented:
- `AppMenuGroup`
- `AppMenuItem`
- `AppPage`
- `FeatureFlag`
- Admin navigation APIs
- User-facing permission-filtered menu API
- Global seed records for active modules and coming-soon modules

Out of scope:
- Frontend rendering
- Business APIs for coming-soon modules
- Inventory, tyres, consumables, attendance, payroll, import/export, bulk upload, accounting, or billing implementations
