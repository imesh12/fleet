# Live Tracking

Page:
- `/tracking/live`

Integrated APIs:
- `GET /admin/tracking/vehicles/latest`
- `GET /admin/tracking/health`

Features:
- Vehicle filter.
- Tracking provider filter.
- Manual refresh.
- Safe 30-second auto-refresh with cleanup.
- Latest coordinates, speed, ignition, last-seen age, provider, and vehicle registry links.

No frontend map dependency was added in this stage.
