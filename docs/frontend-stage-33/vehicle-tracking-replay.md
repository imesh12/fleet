# Vehicle Tracking Replay

Page:
- `/tracking/vehicles/[vehicleId]`

Integrated APIs:
- `GET /admin/tracking/vehicles/:vehicleId/latest`
- `GET /admin/tracking/vehicles/:vehicleId/history`
- `GET /admin/vehicles/:vehicleId/replay`

Features:
- Latest position summary.
- Telemetry event preview.
- Replay-ready ordered position panel.
- Link back to vehicle registry detail.

The replay panel is intentionally map-ready rather than a rendered map.
