# Saved Filter Presets

Integrated APIs:
- `GET/POST/PATCH /admin/report-filter-presets`

Frontend behavior:
- Saved filter presets can be created and edited as JSON.
- Definition detail pages include a preset selector.
- Selecting a preset previews the preset filter JSON.
- Preset application to run payloads is prepared but not overbuilt because report execution is still placeholder-based.
