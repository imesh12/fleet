# Report Definitions

Integrated APIs:
- `GET/POST/PATCH /admin/report-categories`
- `GET/POST/PATCH /admin/report-definitions`

Frontend behavior:
- Categories and definitions can be created and edited from `/reports`.
- Definition detail pages show configuration, filters, columns, and linked category metadata.
- Query configuration and default filters are JSON metadata fields.

Report types:
- vehicle summary
- driver summary
- trip summary
- maintenance summary
- fuel summary
- tracking health summary
- alert summary
- custom
