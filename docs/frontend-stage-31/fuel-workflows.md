# Fuel Workflows

Integrated APIs:
- `GET /admin/fuel/alerts`
- `GET/POST/PATCH /admin/fuel-types`
- `POST /admin/fuel-types/:id/activate`
- `POST /admin/fuel-types/:id/deactivate`
- `GET/POST/PATCH /admin/fuel-vendor-profiles`
- `POST /admin/fuel-vendor-profiles/:id/activate`
- `POST /admin/fuel-vendor-profiles/:id/deactivate`
- `GET/POST/PATCH /admin/fuel-cards`
- `POST /admin/fuel-cards/:id/archive`
- `GET/POST/PATCH /admin/fuel-tanks`
- `POST /admin/fuel-tanks/:id/activate`
- `POST /admin/fuel-tanks/:id/deactivate`
- `GET/POST/PATCH /admin/fuel-policies`
- `POST /admin/fuel-policies/:id/activate`
- `POST /admin/fuel-policies/:id/deactivate`
- `GET/POST/PATCH /admin/fuel-requests`
- `POST /admin/fuel-requests/:id/cancel`
- `GET/POST/PATCH /admin/fuel-entries`
- `POST /admin/fuel-entries/:id/archive`

Fuel receipt fields remain metadata-only.
